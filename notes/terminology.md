# Terminology decisions

Authority chain: Yen Press official EN (series 1) > replacements.yaml > this file.

- 獣人 / 兽人 → **semifer** (never "beastman"; that's the fan term the rules replace)
- 浮遊島 / 浮游岛 → **floating island**; numbered ones are "Island No. N"
- 黄金妖精 → **leprechaun** (the faerie soldiers); 妖精 generally → faerie
- 聖剣 / 圣剑 → **Carillon** (the dug-weapon class name); 遺跡兵装 → dug weapon
- 護翼軍 / 护翼军 → **Winged Guard**
